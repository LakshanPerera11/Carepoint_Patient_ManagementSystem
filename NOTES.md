# CarePoint – Patient Management System (frontend)
Figma: https://www.figma.com/design/LfJvZpngu16iUqCRQBlnkF/CarePoint_HealthCare
GitHub: https://github.com/LakshanPerera11/Carepoint_Patient_ManagementSystem

## Run
Open `index.html` in a browser (no build step). Sign in with any ID and password.
Choose Patient to see the patient view, Admin for the administrator view.

## Files
index.html, patient-dashboard.html, admin-dashboard.html, appointment-booking.html, medical-records.html, billing-payments.html, css/style.css, js/layout.js (shared sidebar/top bar, role-based menu).

## Notes
Plain HTML, CSS, JavaScript. Sample data only. Accessibility: skip link, labelled fields, aria-live errors, error summary, keyboard tabs, focus-visible outline, text+icon status.
